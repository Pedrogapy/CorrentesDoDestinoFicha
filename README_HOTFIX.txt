# Correntes do Destino - Hotfix de Combate v0.4.1

Corrige dois bloqueios do painel do Mestre:

1. O Mestre agora pode resolver qualquer reação pendente de combate.
   Jogadores continuam podendo reagir apenas quando forem o alvo.
2. O painel do Mestre agora possui o botão "Encerrar combate".
   Encerrar não apaga participantes, rolagens nem histórico.

Este hotfix pressupõe que o patch de combate v0.4 já esteja instalado.
Não há migration SQL nova neste hotfix.
